極簡不是風格，它是一種生活態度。

### 極簡的底層邏輯

1. **自我意識**：不被潮流廣告牽著走，主動選擇所愛。
2. **減少選擇**：[固定日常]({{< relref "time.md" >}})，保留決策腦力給重要事情。
3. **關注本質**：重視體驗與價值，而非品牌與所有權。
4. **適當留白**：減少佔據空間、時間、注意力的雜訊。
5. **活在當下**：不後悔過去、擔憂未來，關注於現在。

---
### [《佛教經濟學》](https://findbook.com.tw/9786263181731)

經濟學家舒馬赫（E. F. Schumacher）寫過《小即是美》（_Small Is Beautiful_），第四章就叫「佛教經濟學」，比較了兩種截然不同的經濟邏輯：**傳統經濟學**致力於滿足最大可能的欲望；而**佛教經濟學**則是<span style="color: #fff; text-shadow: 0 0 5px #ff7b23, 0 0 10px #ff7b23, 0 0 15px #ff6b0b;">去除不必要的「想要」</span>。

>商品的擁有與消費只是達成「目的」的「手段」，而佛教經濟學則是探討如何以最少「手段」來達成特定「目的」的系統性研究。

以下是兩種系統的比較：

| 資本主義     | 健康市場          |
| -------- | ------------- |
| 金錢       | 生命            |
| 錢滾錢      | 各取所需          |
| 大公司      | 中小企業          |
| 外部成本     | 使用者付費         |
| 非個人所有權   | 個人、本地業主所有權    |
| 全球化資本    | 本地資本          |
| 投資最大個人利益 | 增加有益成果        |
| 利潤本身是目的  | 利潤是誘因，使投資有助生產 |
| 大企業主導    | 自我組織市場        |
| 合作       | 合作提昇公共利益      |
| 自由貿易     | 公平、平衡         |
| 金錢民主     | 人民民主          |

看來佛陀的極簡與老子的「小國寡民」有異曲同工之妙！
