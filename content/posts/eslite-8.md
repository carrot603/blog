# 11/1（日）

4 : 30 起床，寫一下十月回顧。覺得難得的早晨時光，不應該都拿來輸出，應該趁清醒的時候趕快多輸入，讓知識在腦袋不斷碰撞、發酵。

七點才到誠品，第一次在星期日早上去，一樣沒什麼人。

---

[《人類情感的億萬投射》](https://www.eslite.com/product/10012043902682650339006)，作者 Karl Deisseroth，本書出版於 2024-10。我是因為封面上有貼「2026 諾貝爾生醫獎」才拿來看的。然後隔壁櫃有[《日本職人的科學》](https://www.eslite.com/product/10012023262683178605000)，人人出版。

有一個法國人寫的書，[《八十個台灣關鍵字：一個法國男生眼中的福爾摩沙》](https://www.eslite.com/product/10012010632683233305005)。前幾篇提到什麼惜字塔，要把書燒掉，好恐怖喔！

### [《手機如何毀掉大腦》](https://www.eslite.com/product/10012137252683247312006)

<br>

<img src="https://pub-cbe0ce0485dd4255ac47a58d28e50e0d.r2.dev/eslite-8-1.jpg" style="width: 75%; max-width: 100%; height: auto;">

副標題的長度和排版，根本就是輕小說啊；我覺得這是一種諷刺！

我感覺日本特別愛寫「方法論」耶！尤其會大量列點、清楚排序，還有不知道在正向什麼的肯定句（[AI 文？](/posts/ai/)），看久了不禁感到厭倦！

我猜想，這和日本的社會風氣有關。包括制度化、極致化，和嚴密的階層體系，進而催生出「隨翻隨懂」、「X 個步驟教你變更好」的固定敘事模板。

而歐美就比較少這樣，但這並不代表他們沒有無用雞湯廢話文。他們只是把一個觀點攤開，用完整的故事線，串成一套理論的框架（廢話很多）。日本與歐美，兩者的路線我覺得沒有好壞之分，端看個人需求；當然不用看是最好。

---

劉亦酉[《被認可的努力》](https://www.eslite.com/product/10012030392683227836003)，這是作者的新書，像是[《高產出的本事》](/posts/learning#高產出的本事)我也有看過。稍微翻了一下，我覺得排版和配色都很精美，五種能力看起來都滿有道理的。

雖然我口口聲聲說討厭雞湯商管，但偶爾還是會拿起來翻一下，倒不是想嘲笑他，因為貶低別人不可取，也沒有意義！我大概就是看個目錄，頂多細讀大標題，然後覺得自己該知道的都知道了，於是滿意地闔上書本！而這就是我覺得不太妥當的地方——我在靠商管書尋求認同，確保自己生活在正確的軌道上。首先，根本就沒有所謂「正確的生活」，什麼高效，什麼高能量，不過是壓榨自己的天大謊言！再者，自己的[價值](/posts/core-idea/)只能由自己來賦予，不要去求別人的關注，更不要靠雞湯來安慰自己！

然後翻了一下[《平民股神蘇松泙 4：不蝕本投資漲停股長勝戰法》](https://www.eslite.com/product/10012011762683209195005)。這是九月的新書，當時歷史高點還停在 48,000 的時候，十月到現在就……

# 11/8（日）

今天（真的是今天了！）賴床到八點，烤個吐司，九點出門。

這麼晚去，人明顯變多，座位區聚集了很多長輩；但這並不影響我閱覽，畢竟我都直接就地看書，阻擋動線以外，也妨礙他人找書。

瞥到[《在那故事發生的地方》](https://www.eslite.com/product/10012010632683233301007)，我是被書腰吸引的！「行走本身就是意義」，特別深奧。就像我的興趣，並不是因為興趣帶給我快樂，而是做這件事本身就是快樂！

推薦名單裡，充滿了大咖作家和各路學者，我想他們可能彼此都熟識吧！

### [《飛機解析全書》](https://www.eslite.com/product/10012023262683246311000)

意外地看完了。當下的直覺，它和同為人人出版的[《飛機大圖鑑》](https://findbook.com.tw/9789864613328)內容類似。

我以為這是新系列，回家查資料時，看到內容簡介的最後一行才恍然大悟，「本書為《飛機大圖鑑》（978-986-461-332-8）二版」看來我的記憶是可靠的！

### 《理財聖經》

全名：[《理財聖經：指數投資、持續買、不要賣概念始祖，教你用 ETF 滾出財務自由（30週年經典實踐版）》](https://www.eslite.com/product/10012013192683257298000)

我其實是專程來找這本書的！繞了兩圈都沒看到，想不到它就靜靜躺在我原本一直待的地方。為什麼我會知道這本書呢？是因為我有訂閱博客來的新書通知，偶爾會看一下目錄。一看到這本書的第 18 章寫，「遠離期貨、選擇權與各類衍生性金融商品」，我就繃不住了！

抱著踢館的心態耐心讀完那一章，其他部分我都不看，就斷章取義這一段。總之作者是想表達，衍生性金融商品可以拿來避險；而正因為其高槓桿特性，容易使人貪婪，而後萬劫不復！

做人不可以貪心啊！若妄想靠投機一夜暴富，那還是回家作夢好了！這種不切實際，只想坐吃山空的心態完全不可取！這種人連賺錢、連享受的資格都沒有！

而投資也要看個性，像我沒什麼耐心，慢慢地存股可能不太適合我。當然我也是有長線的部位，我也清楚長期買進的複利效應。

### [《論健康之隱蔽性》](https://www.eslite.com/product/10012013192683210027005)

簡單來講就是：平常你健康的時候，都不好好珍惜；萬一生病了才會意識到，健康是多麼地可貴！感冒還沒完全好，這本書非常適合現在的我！

我想辦法把前言和譯者序通通嗑完，總共約 70 頁。我只有一個結論：**健康的時候好好珍惜，生病的時候多多睡覺！**

  function shuffle(a) {
    for (var i = a.length - 1; i > 0; i--) {
      var j = Math.floor(Math.random() * (i + 1)), t = a[i]; a[i] = a[j]; a[j] = t;
    }
    return a;
  }

  function build() {
    var tiles = shuffle(makeTiles()), picked = {};
    var ov = document.createElement('div');
    ov.id = 'cg-overlay';
    ov.setAttribute('role', 'dialog');
    ov.setAttribute('aria-modal', 'true');
    ov.setAttribute('aria-labelledby', 'cg-title');

    var grid = '';
    for (var i = 0; i < tiles.length; i++) {
      grid += '<button type="button" class="cg-tile" aria-pressed="false" data-i="' + i + '" aria-label="' + tiles[i].label + '">' + tiles[i].svg + '</button>';
    }
    ov.innerHTML =
      '<div class="cg-card">' +
        '<div class="cg-head"><p class="cg-hint">選出所有符合的圖片</p>' +
        '<p class="cg-title" id="cg-title">請選出馬路上的紅綠燈上的蘿蔔</p></div>' +
        '<div class="cg-body"><div class="cg-grid" role="group" aria-labelledby="cg-title">' + grid + '</div></div>' +
        '<div class="cg-foot"><span class="cg-brand">carrot.tw</span>' +
        '<button type="button" class="cg-btn" disabled>驗證</button></div>' +
      '</div>';
    document.body.appendChild(ov);

    var card = ov.querySelector('.cg-card'), body = ov.querySelector('.cg-body'),
        btn = ov.querySelector('.cg-btn'), btns = ov.querySelectorAll('.cg-tile');

    function count() { var n = 0; for (var k in picked) if (picked[k]) n++; return n; }

    for (var b = 0; b < btns.length; b++) {
      btns[b].addEventListener('click', function () {
        var i = this.getAttribute('data-i');
        picked[i] = !picked[i];
        this.setAttribute('aria-pressed', picked[i] ? 'true' : 'false');
        btn.disabled = count() === 0;
      });
    }
    btns[0].focus();

    btn.addEventListener('click', function () {
      var pass = true;
      for (var i = 0; i < tiles.length; i++) {
        if (!!picked[i] !== tiles[i].ok) { pass = false; break; }
      }
      card.className = 'cg-card cg-done';
      if (pass) success(); else fail();
    });

    function success() {
      try { if (REMEMBER) sessionStorage.setItem(KEY, '1'); } catch (e) {}
      body.innerHTML =
        '<div class="cg-result" role="status">' +
          '<svg class="cg-check" viewBox="0 0 52 52" width="84" height="84" aria-hidden="true">' +

          '<p class="cg-ok">驗證成功！</p>' +
          '<div class="cg-spin" aria-hidden="true"></div>' +
          '<p class="cg-sub">正在載入文章…</p></div>';
      setTimeout(function () {
        ov.classList.add('cg-out');
        root.classList.remove('cg-lock');
        setTimeout(function () { if (ov.parentNode) ov.parentNode.removeChild(ov); }, 500);
      }, SUCCESS_DELAY);
    }

          '<div class="cg-spin" aria-hidden="true"></div></div>';
      setTimeout(function () { location.replace(ABOUT); }, FAIL_DELAY);
    }
  }

})();
