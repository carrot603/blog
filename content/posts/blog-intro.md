<br>

### 目錄

僅限長篇文章，方便導引，可以直接按超連結過去。這個就不另外寫腳本了，我的程式只貼在需要目錄的文章。

<br>

### 字數統計

```
ShowReadingTime = true
ShowWordCount = true   
ShowCodeCopyButtons = true
ShowBreadCrumbs = true
ShowShareButtons = false  
``` 

閱讀時間、字數、程式碼複製鈕，以及 BreadCrumbs（完整網站路徑，方便機器人抓取）都有開。但分享我關掉了，因為我希望讀者直接貼網址給別人就好，不需要透過社群媒體。


<br>

### 前後文章

文章末尾有上下一篇文，如果讀者有幸進來我的 blog 逛逛，可以無限讀下去。有些網站就沒有加入這個功能，只能到全文清單一篇篇點出來（還不會自動另開新視窗），我覺得很麻煩！

<br>

### 報紙排版

```
<figure class="newspaper-figure align-left">
  <img src="你的圖片網址.jpg" alt="圖片描述">
  <figcaption class="newspaper-caption">圖一：這是一段置於圖片下方的報紙風格說明文字。</figcaption>
</figure>
```

在[《深度學習的技術》](/deeper-learning)一文，我仿效了報紙，圖文並列。放照片預設就是滿版，把整張照片直接貼在讀者臉上好像不太好！不只版面擠，上下文若被隔開，還會影響閱讀的流暢體驗！目前還在摸索更一目了然的形式，照片下方的說明文字也讓我很苦惱！

（要空一行寫，再空一行放照片；還是用 `>` 隔出一個句子，在視覺上有所留白？目前傾向後者）
