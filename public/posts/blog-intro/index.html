網站功能介紹

July 23, 2026 · 2 min · 738 words

首頁#

極簡風，只留一句話。我是故意預設黑暗模式的，因為這樣才不會刺眼，也可以省電。反正按鈕也在上面，可以自行調整。


選單#

右上角的功能列表。最多有到八個，但我發現在 iPhone 上，六個以上就會自動換行，版面很醜！只好減少到六個。

🥕📝📚🎹👤💡🎲🔍
首頁列表索引頻道aboutnow隨機搜尋
✅✅✅✅✅✅

🥕：最左上角，最下方 Carrot Blog 都可以回到首頁，沒必要多一個按鈕。

🔍：功能不強，不要佔一個位子。


目錄#

僅限長篇文章，方便導引，可以直接按超連結過去。這個就不另外寫腳本了，我的程式只貼在需要目錄的文章。


字數統計#

ShowReadingTime = true
ShowWordCount = true   
ShowCodeCopyButtons = true
ShowBreadCrumbs = true
ShowShareButtons = false

閱讀時間、字數、程式碼複製鈕，以及 BreadCrumbs（完整網站路徑，方便機器人抓取）都有開。但分享我關掉了，因為我希望讀者直接貼網址給別人就好，不需要透過社群媒體。


前後文章#

文章末尾有上下一篇文，如果讀者有幸進來我的 blog 逛逛，可以無限讀下去。有些網站就沒有加入這個功能，只能到全文清單一篇篇點出來（還不會自動另開新視窗），我覺得很麻煩！


報紙排版#

在《深度學習的技術》一文，我仿效了報紙，圖文並列。放照片預設就是滿版，把整張照片直接貼在讀者臉上好像不太好！不只版面擠，上下文若被隔開，還會影響閱讀的流暢體驗！目前還在摸索更一目了然的形式，照片下方的說明文字也讓我很苦惱！
